Secure File Vault is a comprehensive security-focused platform that enables users to safeguard their files with encryption, manage access controls, and monitor activity logs.

### Key Features:

Secure File Sharing: Registered members can securely share files with other verified members. Files are automatically encrypted before sending and decrypted upon receipt.

User and Admin Profiles: Both users and admins have detailed profiles storing personal information.

Role-Based Access Control: Admins can manage user privileges, including granting or revoking access to firewall status and log viewing, either globally or individually.

New User Sign-Up: New members can easily register by filling in their personal details and become part of the vault.

Firewall and Log Management: Admins maintain oversight of system firewall settings and activity logs, ensuring robust security governance.

Secure your files. Share with trust. Govern with control.
